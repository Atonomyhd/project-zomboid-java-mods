Universal Admin Core 0.1.8
Requires Project Zomboid Build 42 and matching Storm on server and clients.

Drag the bottom-right grip to resize; drag the header to move.
Ctrl+A opens search when not typing. Up/Down selects; Enter opens; Escape closes.
Search includes Brush Tool and native admin/debug tools. Native permissions apply.
Click a group to expand/collapse it. Arrow carets show its state.
Make Noise has one group with radius choices. Unavailable debug tools are hidden.
Object-specific tools remain in the original right-click menus.
